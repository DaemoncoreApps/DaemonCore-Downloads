# DaemonCore Academy 9.0.5

DaemonCore Academy 9.0.5 makes FieldOps part of the Academy product instead of a separately paid unlock.

## What changed

- FieldOps is included with the Windows Academy package and free Linux release.
- Removed the FieldOps license-required screen and Lemon Squeezy checkout path from the product flow.
- FieldOps operations still require a protected operator identity, written authorization, exact targets and ports, an active signed engagement, and evidence integrity checks.
- Existing FieldOps license records remain readable for compatibility; they no longer gate access.
- Cloud Classroom educator services remain separate.

## Distribution

- Windows: official Microsoft Store package.
- Linux: free AppImage and Debian packages through DaemonCore Downloads.
- Academy training and local FieldOps operations remain available without a FieldOps purchase.
