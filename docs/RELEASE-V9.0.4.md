# DaemonCore Academy 9.0.4

DaemonCore Academy 9.0.4 is the reliability and desktop-quality release for Windows and Linux.

## What changed

- Faster first launch through parallel local-store initialization.
- Clear renderer recovery state instead of an unexplained blank screen.
- Living Range startup now detects Docker subnet conflicts, selects an available isolated private subnet, and cleans stale Compose resources before launch.
- Lab Range and Living Range layouts were refined for laptops, desktops, and smaller windows.
- Dark scrollbar, spacing, typography, and responsive presentation were polished across the desktop experience.
- Interactive workbench completion and evidence handling were strengthened.
- Local progress, settings, records, and licensing remain preserved during upgrades.
- The Windows package identity remains unchanged for Microsoft Store updates.

## Linux release

- `DaemonCore-Academy-9.0.4.AppImage`
- `DaemonCore-Academy-9.0.4.deb`
- SHA-256 checksums and the Linux support matrix are published with the release.
- Academy remains free on Linux.
- Disposable live ranges require Docker Engine with Compose v2.
- FieldOps is included with Academy; Cloud Classroom educator services remain separate.

## Product scope

The release carries the Academy curriculum, practical workbenches, sealed Docker ranges, Living Range environments, local progress records, evidence artifacts, and the Web/API workbench. CORE 02 development material remains gated and is not advertised as a public release feature.
