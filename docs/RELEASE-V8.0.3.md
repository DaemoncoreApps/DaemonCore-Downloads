# DaemonCore Academy 8.0.3

DaemonCore Academy 8.0.3 is the supported Linux release for x64 Ubuntu and Debian-family desktop systems.

- AppImage and Debian packages are built on Ubuntu CI.
- SHA-256 checksums and the Linux support matrix ship with the release.
- Academy lessons remain available offline.
- Live ranges require Docker Engine with Compose v2.
- Windows customers should use the official signed Microsoft Store package.

The Academy is free. FieldOps professional features and Cloud Classroom educator features remain optional services with separate licensing requirements.
