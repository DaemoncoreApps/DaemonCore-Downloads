# DaemonCore Academy 10.0.0

DaemonCore Academy 10.0.0 is the free-entry release for Windows and Linux.

- CORE 01, FieldOps, Mission OS, local records, and sealed ranges are included.
- CORE 02 adds 144 advanced units and is included at no charge on Linux.
- Windows customers can unlock CORE 02 once for $9.99 through Lemon Squeezy.
- Windows customers should use the official signed Microsoft Store package.
- Linux customers can use the AppImage or Debian package from the `v10.0.0` release.
- Docker Engine with Compose v2 is required for container-backed ranges.
- Verify `SHA256SUMS-linux.txt` before launching a Linux package.

The public release does not automatically issue DCCO credentials. Cloud Classroom educator services remain separate.
